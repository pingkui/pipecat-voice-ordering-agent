# 安全与隐私说明

这是一个演示项目,不是加固过的服务。下面是我知道的风险,以及哪些做了处理、哪些没有。

## 不要原样暴露到互联网
- `bot.py` 提供一个**没有登录**的浏览器客户端,并且会为任何连接的人调用收费的 API(语音识别、语音合成、LLM)。能访问这个端口的人,就能花你的钱。它监听 `127.0.0.1`,请保持这样,或者在前面加上认证、限流和消费上限。
- 开发用的 runner 允许任意网页来源。在 localhost 上没问题,放在公网地址后面就不行。

## 来电者是不可信的输入
来电者说的任何话都会被转写并交给模型,所以来电者可以试图劝说模型做某些事("忽略你的规则"、"老板说免费")。能限制损害的是:
- **模型改不了价格。** 总价由代码根据菜单计算,没有任何设置价格的工具。
- **没有闸门,模型下不了单**(最新的读回、来电者在读回之后说过话、之后没有改动)。
- **工具参数会被校验**(1 到 20 的整数数量、已知的菜品编号、营业时间、人数)。
- **没有被阻止的:** 模型仍可能被说动而措辞不当、不必要地转接真人,或者把一句无关的"好"读成确认。在厨房据此行动之前,应该有人能复核订单。

## 个人数据
- 姓名、配送地址和点了什么,会经过语音和模型服务商,也会出现在 bot 的日志里(INFO 日志会打印工具参数)。`calls.jsonl` 为每通电话保存一条带姓名和地址的摘要。
- 这里没有任何删除或匿名化的机制,也没有保留期限的策略。接真实来电者之前请先补上。
- 录音或转写通话可能需要征得同意,各国规定不同。部署前请先核实。

## 密钥
- API 密钥从环境变量读取。`.env` 和日志文件都在 `.gitignore` 里。
- 绝不要提交密钥;如果密钥曾经被贴进仓库里的某个文件,请轮换它。

## 以后如果接电话线路
- 一个电话号码会招来**盗打和骚扰电话**。使用运营商的消费上限和白名单,并限制通话时长。
- 电话音频比浏览器麦克风质量差;语音识别会更差,延迟需要重新测量。

## 过敏
agent 会列出菜单数据里的过敏原,并把所有过敏问题转给真人。它被要求绝不承诺某道菜是安全的,测试也检查了过敏问题最终会转接。请把它当作一道防护,而不是保证。
